Grand Canvas

A party drawing game, made by Whose?Games.

Everyone gets a wonky homework problem, everyone draws the answer, and then everyone finds out whose drawing actually made sense. Play with strangers in a ranked match, or start a private room and share the code with friends.

There's also a daily prompt everyone in the world draws the same thing for, and a leaderboard that tracks how good you actually are at this.
