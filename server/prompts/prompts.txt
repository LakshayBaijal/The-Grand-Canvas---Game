# Fill-in-the-blank prompts for Grand Canvas.
#
# One per line. Each line must contain exactly one blank, written as ___
# (three underscores). A round picks a line, one player fills the blank, and
# the finished sentence is what everyone draws.
#
# Lines starting with # are comments, and blank lines are ignored. Edit this
# file and restart the server -- nothing else needs changing, and no code
# needs rebuilding for a wording fix.
#
# What makes a good one:
#
#   * It is a sentence people already half-know, so the writer has somewhere
#     to start. Forty seconds is not long to be witty from nothing.
#   * The blank asks for ONE thing -- a noun, a person, a place -- not a
#     clause. The answer is also what the bots draw, so it has to name
#     something drawable.
#   * It is for grown-ups: work, money, family, the city, getting older.
#     Playable with your boss in the room, but not written for children.
#   * Clean. Player-typed text is filtered (see profanity.ts); prompts
#     themselves should never need it.
