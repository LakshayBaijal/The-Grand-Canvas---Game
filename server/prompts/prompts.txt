# Fill-in-the-blank prompts for Grand Canvas.
#
# One per line. Each line must contain exactly one blank, written as ___
# (three underscores). A round picks a line, one player fills the blank, and
# the finished sentence is what everyone draws.
#
# Lines starting with # are comments, and blank lines are ignored. Edit this
# file and restart the server -- nothing else needs changing, and no code
# needs rebuilding for a wording fix.
#
# The test for every line: would an ordinary person, reading it once, know
# what kind of word goes in the blank -- and could someone draw that word?
#
#   * A saying people already know, with the well-known word taken out.
#   * Or a plain everyday sentence whose blank wants a THING: an object, an
#     animal, a food, a person. Not an idea, not a feeling.
#   * Short. Clean. No idioms that need explaining.
#
# Player-typed text is filtered (see profanity.ts); prompts themselves
# should never need it.
